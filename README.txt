# DoggieStore

Página web responsive inspirada en el diseño proporcionado.

## Estructura

DoggieStore/
├── index.html
├── style.css
├── script.js
└── img/
    └── hero-doggiestore.png

## Cómo abrirlo en Visual Studio

1. Descomprime la carpeta.
2. Abre la carpeta `DoggieStore` en Visual Studio / Visual Studio Code.
3. Abre `index.html` con tu navegador.
4. Para una experiencia más cómoda en Visual Studio Code, puedes utilizar la extensión "Live Server".

## Funcionalidades incluidas

- Diseño responsive para móvil, tablet y ordenador.
- Menú móvil.
- Navegación suave entre secciones.
- Cambio automático del enlace activo al hacer scroll.
- Carrito de demostración con contador.
- Botón de búsqueda con ventana modal.
- Año automático en el footer.
- Imagen del diseño incluida en `img/hero-doggiestore.png`.

## Nota

La búsqueda y el carrito son funcionalidades de demostración en JavaScript. Para una tienda real habría que conectarlos a productos, base de datos, pagos y backend.
